# 7design

> Creative agency website for 7 Design (Egypt). Brand identity, graphic design, printing, photography, media production, and motion graphics. Live site used as portfolio and lead-generation channel.

## Links

- Site: [https://7design-eg.com/](https://7design-eg.com/)
- Sister brand: [http://keyframe-eg.com](http://keyframe-eg.com)

## What it is

- **Home**: hero, filterable portfolio grid (All / Branding / Design / Printing / Video Production), services overview, Vimeo showreel, vision block, client logo wall, newsletter signup, multi-country contact footer.
- **Portfolio**: ~20 case entries (Keyframe, Shikhon Foods, Nelover Perfumes, Alkesai Foundation, Green Medical PolyClinic, TAS Group, Thebax, Elsewedy Indoor & Outdoor, European Union Booklet), each on `/page/p/<slug>`.
- **Services**: Photography, Media Production, Branding, Design with detail pages.
- **Clients**: European Union, IBM, Google, Vodafone, Aramex, TEDx, IEEE, Siemens.
- **Contact**: offices across Germany, Turkey, Egypt, Saudi Arabia, UAE, Kuwait.



## Frontend developer role

- Built and maintained marketing pages from design mockups: header/nav with dropdowns, hero, portfolio grid, services cards, client strip, footer.
- Implemented portfolio filtering by category and card layouts with fixed image renditions (`600x800`, `1000x667`) for a consistent grid.
- Integrated Vimeo showreel embed and social links (Twitter, Facebook).
- Built newsletter signup with client-side validation states (invalid email, success, service-unavailable).
- Kept theme assets (`/Front/img/...`) and CMS uploads (`/upload/...`) organized and performant across pages.
- Ensured navigation, layout, and media held up across desktop and mobile viewports.
