# Techtionary (ThinkTech) — Technical Terms Glossary

> Bilingual Arabic/English glossary of technical terms by ThinkTech. Short encyclopedia entries with social sharing, "most searched terms" ranking, and per-term detail pages.

## What it contains

- **Homepage**: "معجم المصطلحات التقنية" with most-searched tabbed entries — Cloud, Cloud Computing, Blockchain (`/share/<id>/<slug>`) — each with excerpt and "Read more."
- **Term pages**: definition body plus per-network share endpoints (Facebook, LinkedIn, Twitter, WhatsApp).
- **Chrome**: dark/light logo variants, Arabic/English toggle, A+/A- font-size controls.
- **Footer**: "© 2020 ThinkTech."



## Frontend developer role

- Built bilingual UI with Arabic-first RTL layout and English toggle, including mirrored chrome and logo variants.
- Implemented tabbed "most searched" ranking UI and term excerpt cards linking to detail pages.
- Built per-term share rows for four networks with correct share-URL wiring.
- Added readability controls (font-size A+/A-) and kept long-form definitions legible on mobile and desktop.
- Structured the dictionary content model in the UI (numeric-ID routes, slug display) so new terms drop in without layout work.
